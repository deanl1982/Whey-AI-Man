# 0.4 — The AI Periodic Table

**Whey-AI-Man** | Lunch & Learn Series

## tl;dr

A framework for organising the chaos of AI terminology. Inspired by [IBM Technology's AI Periodic Table](https://www.youtube.com/watch?v=YOUR_VIDEO_ID), this session maps 18 AI concepts into a periodic table where — just like chemistry — position predicts behaviour.

## The idea

The world of AI is flush with new, exciting, and misunderstood terms. Agents. RAG. Embeddings. Guardrails. Function calling. Vector databases. Everyone's talking about them, nobody agrees on how they fit together.

Chemistry had the same problem. Before Mendeleev, chemists had dozens of elements and no shared mental model. He built a grid where rows told you complexity and columns told you behaviour — and the gaps predicted elements nobody had discovered yet.

This session applies the same thinking to AI.
