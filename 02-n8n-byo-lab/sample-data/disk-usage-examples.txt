## LLM Prompt Examples

### Prompt 1: Simple Path Identification

You are a Linux sysadmin. The /tmp directory is at 87% usage. Here are the largest items:

1.0G    /tmp/logs
50M     /tmp/systemd-private-xxx
12M     /tmp/snap.docker

Based on this, what directory should we clean up? Respond with ONLY the path, nothing else.

Expected Response: /tmp/logs

### Prompt 2: With Context

You are a Linux sysadmin managing a production server. The /tmp directory is at 92% usage, which is critical. Here are the largest directories:

400M    /tmp/data/important.db
300M    /tmp/cache/session-files.tmp
200M    /tmp/logs/app.log

The /tmp/data contains a database file (important).
The /tmp/cache contains temporary session files (safe to delete).
The /tmp/logs contains application logs (safe to delete old logs).

Which directory is the safest to clean up? Respond with ONLY the path.

Expected Response: /tmp/cache

### Prompt 3: Multiple Options

You are a Linux sysadmin. The /tmp directory is at 88% usage. Here's what's using space:

500M    /tmp/logs/app.log
300M    /tmp/logs/old.log
200M    /tmp/logs/archive-2020.log

All files are log files. Which specific file should we delete first? Consider that:
- app.log is actively being written to
- old.log is from last month
- archive-2020.log is from 2020

Respond with the full path to the safest file to delete.

Expected Response: /tmp/logs/archive-2020.log

## find Command Examples

### Example 1: Find Files Older Than 7 Days

$ find /tmp/logs -type f -mtime +7
/tmp/logs/old.log
/tmp/logs/archive-2020.log

### Example 2: Find and Delete Files Older Than 7 Days

$ find /tmp/logs -type f -mtime +7 -delete

### Example 3: Find Log Files Older Than 30 Days

$ find /tmp/logs -type f -name "*.log" -mtime +30
/tmp/logs/archive-2020.log
/tmp/logs/backup-2021.log

### Example 4: Find Large Files (>100MB)

$ find /tmp -type f -size +100M
/tmp/logs/app.log
/tmp/data/important.db
/tmp/cache/large-cache.tmp

### Example 5: Find and List with Details

$ find /tmp/logs -type f -mtime +7 -ls
1048577  512 -rw-r--r--   1 user user  314572800 Jan 15 2020 /tmp/logs/archive-2020.log
1048578  512 -rw-r--r--   1 user user  314572800 Dec 20 2025 /tmp/logs/old.log

## Common Errors and Troubleshooting

### Error 1: Permission Denied
$ du -sh /tmp/*
du: cannot read directory '/tmp/systemd-private-xxx': Permission denied

Solution: Redirect errors to /dev/null
$ du -sh /tmp/* 2>/dev/null

### Error 2: Command Not Found (awk)
Solution: Use alternative parsing
$ df -h /tmp | tail -1 | cut -d' ' -f5

### Error 3: Ollama Not Responding
$ curl http://localhost:11434/api/generate
curl: (7) Failed to connect to localhost port 11434

Solution: Check if Ollama is running
$ ps aux | grep ollama
$ ollama serve

### Error 4: find Command Deletes Nothing
$ find /tmp/logs -type f -mtime +7 -delete
(no files deleted)

Reason: No files older than 7 days
Solution: Check file ages first
$ find /tmp/logs -type f -mtime +7 -ls
